Is it safe? - OXT Community Stacks

Is it safe to play a stack here?

Yes. A stack on this site plays inside a boxed-in part of the page. It cannot reach your files, your programs or anything else on your computer, and it cannot see what you do on other web sites.

What a stack is

A stack is a small program that somebody made with OXT-Beyond, and a program does what its author wrote. So this site does not rely on trusting every author. It relies on where the stack runs.

How each stack is kept in its box

  • It runs in your web browser, not on your computer. A browser never lets a page open your files or start programs, and the same holds for a stack that plays in one.
  • Every stack gets a box of its own. The page tells the browser to treat the playing stack as a stranger: it cannot read this site's saved data, it cannot see another stack's, and it cannot send you to another page.
  • Nothing is kept. What a stack saves (a high score, a note) lives only while the page is open. Use the stack's own export or download button for anything you want to keep.

How each stack is checked before it is listed

  • A person looks at every stack before it appears here.
  • A checker reads every script in it and writes the labels you see on its page, such as Uses the internet. They tell you what the stack reaches for.
  • Some things are never accepted: stacks with a password (nobody could read their scripts), stacks that bring native code, and stacks that try to run other programs.
  • Anyone can read every script of every stack. Each stack's page has a link.

The one thing to be careful with

If you download a stack and open it in OXT-Beyond on your own computer, it is no longer in a box. There it can do what any program can do. Read its scripts first, and open stacks only from people you trust, as you would with anything you download.

Script libraries are different

The libraries on this site are not stacks to play. A library is a script that you install into OXT-Beyond, to use in stacks of your own. An installed library is not in a box. It runs on your computer as any program does, each time OXT-Beyond starts and in every program you build with it.

  • A library here is always plain text. Every line of it is on its page, and the file you download is made by this site from that same text.
  • A checker and a person read each library before it is listed. Its page says what it reaches for, such as the internet or files.
  • Libraries that bring native code, start other programs or hide their script are never accepted.
  • That is care, not a guarantee. Read a library before you install it, and install only from people you trust.
  • Many libraries have a demo: a stack that uses the library and plays here in your browser, boxed in. Trying the demo puts nothing on your computer.

Something looks wrong?

Every stack's page has a Report a problem link. You can also tell us on the OpenXTalk forum. A stack that turns out to be a problem is taken down.
